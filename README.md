# 真实的世界 · RealWorld Sim

一个"按物理规律说话"的工程沙盒：把零件、材料、液体、电机、PLC 程序放进去，软件按真实物理算它
**扛不扛得住、转不转得动、热不热、做不做得出来**——目标是像《我的世界》一样搭东西，但搭出来的东西在现实里真的能做。

> 现阶段是工程估算工具，不能替代实测和正式设计校核。每个模块都写明了哪些已验证、哪些是估算。

## 现在能做什么（v0.10）
| 页签 | 内容 |
|---|---|
| ① 感应加热淬火 | 二维轴对称有限元：线圈涡流/集肤效应 → 焦耳热 → 瞬态传热 → 喷淋/浸入淬火 → 硬化层、硬度估算、火色外观、过烧/熔化报警；可选非线性 B-H（含居里点）和线圈导磁体（硅钢叠片/SMC/铁氧体） |
| ①b 电磁升级 | B-H 曲线与居里点、导磁体对比（电流/效率/损耗/轴向加热图形）、全三维涡流（Nédélec 棱边单元，偏心工件的周向温差，对二维轴对称验证） |
| ② 结构受力 | 三维梁有限元机架：选尺寸、型材、材料（钢/铝/不锈钢/塑料）、载荷 → 变形、应力、屈曲、地脚是否翘起；板单元（Morley）算圆盘/台板；螺栓预紧与滑移校核 |
| ③ PLC 虚拟调试 | 三菱 FX3U 指令表解释器（LD/AND/OR/ANB/ORB/MPS/SET/RST/PLS/PLF/MOV/CMP/ZRST/SFTL/INC/DINC/ALT/STL/RET、T/C）。在软件里直接写程序，带着设备模型（气缸按气压/负载算动作时间、感应加热有限元给出测温信号）实时运行，看 I/O 灯和动画 |
| ④ 物理沙盒 | 压力表沉到任意液体（可填比重 0.7 等）任意深度：静压、该深度沸点、量程、外壳额定水深换算、耐温、浮力、腐蚀；管路/水泵/喷嘴求工作点和压降分布；异步电机铭牌→机械特性、起动仿真、起停次数、参数是否违反物理；连续运行：水箱热平衡、冷水机负荷、淬火液浓度/温度、淬裂倾向、余热自回火硬度 |
| ⑤ 材料库 | 118 种元素周期表（密度、熔点、电阻率、导热、比热、弹性模量、线膨胀、晶体结构、价格；开源数据 pymatgen + mendeleev）；31 个常用牌号的标准/手册性能；任意配比“配合金”：先判断能不能互溶（二元相图结论 + Miedema 混合焓 + Hume-Rothery 规则，例如铁+银液态就分层），再按混合法则算密度/成本/模量范围，成分对上牌号给实测强度，否则只给标明“粗估”的范围 |
| ⑥ 电路/示波器 | ngspice 仿真（瞬态/交流/直流），导入 KiCad 网表（.cir / .net）；虚拟示波器：4 通道（任意网络、差分、电流）、10×8 格、伏/格、偏移、DC/AC 耦合、时基旋钮、边沿触发 Auto/Normal/Single、时间/电压光标、10 项自动测量、FFT（5 种窗，dBV）、Auto Set。示例：RC、RLC 谐振、桥式整流、运放振荡器、MOSFET 半桥+串联谐振（感应加热拓扑） |
| ⑦ 单片机/PLC | 自写 AVR 指令子集模拟器（ATmega328P 风格，周期精确）+ 汇编器（不需要编译器）+ 通用外设（GPIO、定时器/PWM、10 位 ADC、UART、外部中断）；行为级 Python 固件模式；可选 unicorn Cortex-M 核心。和 FX PLC、半桥电路联合仿真（统一时间轴、事件按时间排序）：PLC 发启动 → 单片机 PWM 软启动 → ADC 读电流 → 过流封锁 → 报警回 PLC 停机；时序图、引脚/寄存器、梯形图与 I/O 灯、串口终端，波形可送到 ⑥ 示波器 |
| ⑨ 三维装配世界 | 摆方块/板/梁/圆柱/圆管/球（真实材料密度），“放手”让重力、碰撞、摩擦起作用（MuJoCo 刚体）：倒不倒、滑不滑、地面/接触压强超不超、梁的弯矩应力挠度、落重冲击、水里浮沉；3D 视图可旋转、逐帧回放 |
| ⑧ 整机联动 | 上电 → PLC 顺序 → 预充电/旁路 → 变频器固件 → 三相整流+母线+全桥串联谐振 → 气缸 → 感应加热(红外测温) → 喷淋淬火 → 水箱/线圈温升，一条时间轴跑完整台机器。可注入缺水（含“联锁被短接”）、电网跌落、气压低、预充电太短、PLC 编程错误，快进 8 小时看水箱升温对喷淋的影响；PLC 程序可直接改 |

## 安装（Ubuntu 22.04 / 24.04 桌面）
```bash
./install_ubuntu.sh   # 第一次
./run.sh              # 打开软件
.venv/bin/python validate.py   # 自检
```
电路仿真需要 ngspice：`install_ubuntu.sh` 里已包含 `sudo apt install ngspice`。
可选的 Cortex-M 核心需要 unicorn：`./install_ubuntu.sh --with-unicorn`（或 `.venv/bin/pip install unicorn`），不装也能用其它全部功能。

## 已验证（validate.py）
- 集肤深度：有限元 vs 理论 < 3%；能量守恒：输入 10000 J，工件吸收 9949 J
- 悬臂梁挠度 = 材料力学公式；环形板外缘挠度 vs 解析解 0.4%
- 10 m 水柱 98.07 kPa；水沸点 100.00 °C；200 °C 饱和压力 1.552 MPa（蒸汽表 1.555）
- 层流摩擦系数 64/Re；电机额定点转矩 = P/ω
- PLC 演示程序：加热/淬火时间与程序设定一致
- 电路/示波器（ngspice 44.2）：RC τ 与 63.2% 点误差 <0.01%，上升时间 2.197τ 误差 -0.02%；RLC 谐振频率误差 <0.001%；
  运放振荡器频率 vs 2RC·ln3 误差 -0.43%（行为级运放压摆率有限）；FFT 方波 3/5 次谐波 = 1/3、1/5；
  示波器 Vpp/Vavg/Vrms/频率/占空比 与解析值一致；整流纹波比近似公式 I/(2fC) 小 18%（公式本身偏保守）
- 电磁升级（v0.9）：非线性谐波平衡 vs 一维时域真值 <1.0%（20–700°C，5–80 kA/m）；线性极限 vs 解析 <0.3%；三维 vs 二维轴对称 −2.5%（粗网格，最低阶棱边单元）；偏心引起的周向功率差是模型结果，未经实测；
- 整机联动（ngspice 44.2）：全桥方波→串联 RLC 的功率，基波近似 vs ngspice 偏差 <0.5%；合旁路冲击电流 RK4 vs ngspice <0.01%；预充电 RC 指数 <0.2%；
  电网→母线→逆变器→线圈/工件能量守恒 <0.2%；加热 3 s 工件吸收 17.89 kJ（有限元表 17.83 kJ）；缺水 → 高频关断 720 ms（预计 708 ms + 扫描）
- 三维装配世界（v0.10，MuJoCo 刚体）：自由落体 g 0.00%；钢板桥弯矩 +0.04% / 挠度 +0.04% vs 材料力学；斜面临界角 26–27°（理论 26.57°）、滑动加速度 −0.3%；橡胶块倾倒临界 17.5–19.5°（理论 18.43°）；叠积木临界外伸 0.95–1.05（理论 1.0）；台架反力 −0.21%
- 材料库：混合法则密度 vs 31 个牌号实测平均偏差 1.3%（最大 3.6%）；互溶模型 vs 二元相图结论 84% 一致
- 单片机（按 AVR 指令手册周期数 / ATmega328P 手册公式，没有和真芯片逐周期对照）：一次延时循环 4613 周期与手工计数一致；中断响应 11 周期；
  定时器溢出 976.5625 Hz、CTC 2000 Hz、Fast PWM 20 kHz/30%、62.5 kHz/25%、反相 25%、OCR=0 → 1/256，全部与公式一致；
  ADC 量化误差最大 0.96 LSB、平均 -0.479 LSB（理论 -0.5）、标准差 0.289 LSB（理论 0.2887）；UART 9615.38 波特，TX 波形独立解码正确
- 联合仿真：按钮 → PLC 输出 12.0 ms（窗口 12–14 ms）；PLC 输出 → 单片机动作 0.2 ms + 21 周期；ADC 超限 → 关驱动 24.562 µs（与理论一致）；
  电流越线 → 关驱动 69.3 µs（窗口 24.6–74.6 µs）

## 主要近似（未实测校准）
- 磁导率用随温度变化的有效 μr，不是完整 B-H 曲线；淬火换热系数为典型曲线
- 硬度按 45 钢 CCT/回火规律估算，不是金相计算
- 机架接点按刚接；焊缝强度、振动、疲劳未算
- 管路局部阻力系数取手册典型值；电机特性由铭牌推算（Kloss 公式修正）
- 示例里的二极管/三极管/功率 MOSFET/运放是通用模型（典型参数），不是具体厂家型号；要和真板子对比请换成厂家 SPICE 模型
- 示波器的 AC 耦合用“减去整段记录平均值”近似，不是真机的 ~10 Hz 高通；上升时间按屏幕内 Vmin/Vmax 定 10%/90%
- 任意配比合金的熔化范围、电阻率、强度只是粗估范围；浓合金电阻率（镍铬、钛合金）会超出估算上限
- 单片机是 AVR 指令子集，汇编器输出内部指令表（不生成 .hex，不能直接跑 avr-gcc 固件）；没有 Timer1/SPI/I²C/看门狗/EEPROM；引脚输入无同步器延时
- PLC 输入滤波 10 ms、输出延时 0.2 ms、扫描 2 ms 是假设值；行为级固件、ngspice 回放、unicorn 计时都是估算
- 整机联动：主回路是基波平均模型（微秒级开关波形看 ⑥/⑦）；变频器固件是 Python 行为级；工件加热按“能量等效时间”查恒功率有限元表（变功率时表面/心部温度分布与恒功率不同，近似）；
  机器参数（10 kW 级、30 kHz、母线 2 mF、预充电阻 100 Ω、线圈热容、保护阈值、线圈 150°C 损坏线、淬火液 45°C 线）都是假设值，不是某台设备实测
- 整机联动：主回路是基波平均模型（微秒级开关波形看 ⑥/⑦）；变频器固件是 Python 行为级；工件加热按“能量等效时间”查恒功率有限元表（变功率时表面/心部温度分布与恒功率不同，近似）；
  机器参数（10 kW 级、30 kHz、母线 2 mF、预充电阻 100 Ω、线圈热容、保护阈值、线圈 150°C 损坏线、淬火液 45°C 线）都是假设值，不是某台设备实测

- 三维装配世界：摩擦系数是典型值、取两种材料较小者（估算）；接触是 MuJoCo 软接触，冲击峰值力不可信，落重冲击用材料力学公式给保守上界；梁校核是沿长轴一维、接触点分布决定载荷分布（超静定时是近似）；焊成一组的零件当刚体，只校核整体稳定与地面压强；不含浮力动力学/空气阻力/破坏后碎裂/疲劳；渲染是软件画家算法，穿插很多的复杂场景会有锯齿
