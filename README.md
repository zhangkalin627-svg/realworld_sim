# 真实的世界 · RealWorld Sim

一个"按物理规律说话"的工程沙盒：把零件、材料、液体、电机、PLC 程序放进去，软件按真实物理算它
**扛不扛得住、转不转得动、热不热、做不做得出来**——目标是像《我的世界》一样搭东西，但搭出来的东西在现实里真的能做。

> 现阶段是工程估算工具，不能替代实测和正式设计校核。每个模块都写明了哪些已验证、哪些是估算。
> 给 AI 代理：本仓提供 [llms.txt](llms.txt)（机器可读能力/接口/反馈入口）与 `python3 diag.py`（诊断摘要 JSON）；Web 版 OpenAPI 在 `/openapi.json`。
> 每个模块"干什么+一键示例+看什么"见 [docs/GUIDE.md](docs/GUIDE.md)。

## 项目定位（用户 2026-10-13 阐述）
做淬火设备和电源的目的是能真正生产。现实中电源易出故障，要靠测试和版本升级持续优化性能，尽量缩小理论与现实的差距。本软件的作用是在设备做出之前和之后，在软件里模拟真实设备长时间运行、暴露问题，并区分是软件的问题还是设备设计的问题。两套系统——真实设备（hfq6-design 仓）与本仿真——对照走。

**项目方向（2026-10-13 用户定）**：仿真阶段不计较器件成本，优先功能做满测透；功能立住后再做降本迭代。功率等级逐级爬升：先把 100 kW 级做到优秀，再研发更高等级。

## 安装（Ubuntu 22.04 / 24.04 桌面）
```bash
./install_ubuntu.sh   # 第一次
./run.sh              # 打开软件
.venv/bin/python validate.py   # 自检
```
电路仿真需要 ngspice：`install_ubuntu.sh` 里已包含 `sudo apt install ngspice`。
可选的 Cortex-M 核心需要 unicorn：`./install_ubuntu.sh --with-unicorn`（或 `.venv/bin/pip install unicorn`），不装也能用其它全部功能。
可选的非圆截面涡流需要 gmsh：`pip install gmsh`，不装也能用其它全部功能。

架构约定面向中期目标——**自由组合"拼设备"（电源板 + PLC + 变频器 + 机械件任意组合）+ 长时连续运行（100 h 级、加速仿真）**：模块注册表的参数/结果都是纯 JSON、运行函数无状态，后续"拼设备"就是部件连接拓扑 JSON 由图执行器组合模块；长任务将换持久化任务表 + 断点续算（任务表已持久化 SQLite，感应淬火支持断点续算）。

## 主要近似（未实测校准）
- 磁导率用随温度变化的有效 μr，不是完整 B-H 曲线；淬火换热系数为典型曲线
- 硬度按 45 钢 CCT/回火规律估算，不是金相计算
- 机架接点按刚接；焊缝强度、振动、疲劳未算
- 管路局部阻力系数取手册典型值；电机特性由铭牌推算（Kloss 公式修正）
- 示例里的二极管/三极管/功率 MOSFET/运放是通用模型（典型参数），不是具体厂家型号；要和真板子对比请换成厂家 SPICE 模型
- 示波器的 AC 耦合用“减去整段记录平均值”近似，不是真机的 ~10 Hz 高通；上升时间按屏幕内 Vmin/Vmax 定 10%/90%
- 任意配比合金的熔化范围、电阻率、强度只是粗估范围；浓合金电阻率（镍铬、钛合金）会超出估算上限
- 单片机是 AVR 指令子集，汇编器输出内部指令表（不生成 .hex，不能直接跑 avr-gcc 固件）；没有 Timer1/SPI/I²C/看门狗/EEPROM；引脚输入无同步器延时
- PLC 输入滤波 10 ms、输出延时 0.2 ms、扫描 2 ms 是假设值；行为级固件、ngspice 回放、unicorn 计时都是估算
- 整机联动：主回路是基波平均模型（微秒级开关波形看 ⑥/⑦）；变频器固件是 Python 行为级；工件加热按“能量等效时间”查恒功率有限元表（变功率时表面/心部温度分布与恒功率不同，近似）；
  机器参数（10 kW 级、30 kHz、母线 2 mF、预充电阻 100 Ω、线圈热容、保护阈值、线圈 150°C 损坏线、淬火液 45°C 线）都是假设值，不是某台设备实测

- 三维装配世界：摩擦系数是典型值、取两种材料较小者（估算）；接触是 MuJoCo 软接触，冲击峰值力不可信，落重冲击用材料力学公式给保守上界；梁校核是沿长轴一维、接触点分布决定载荷分布（超静定时是近似）；焊成一组的零件当刚体；不含浮力动力学/空气阻力/破坏后碎裂/疲劳；渲染是软件画家算法，穿插很多的复杂场景会有锯齿
- v0.12：型材按尖角分解，质量/惯量比 GB 理论值偏轻 1–5%（忽略圆角）；槽钢/角钢非对称截面只算竖向力绕水平形心轴的弯曲，不算扭转/双力矩与剪切中心；
  螺栓组是 bearing 型弹性分配（直接剪+偏心转动剪+轴向拉+弯矩），不含撬力放大、预紧力、被连接件变形与承压板校核；螺栓只算拉不算压（压由被连接件接触传）；
  轴承只有深沟球径向载荷（P=Fr），额定为典型样本值，不含寿命修正 a_ISO；赫兹接触是静态弹性解，p0 超屈服不一定失效；断裂判据只看最大应力 vs 抗拉强度，不含应力集中系数、裂纹与疲劳

- 流体：水锤不模拟汽穴（负压到蒸气压后的撞击更大，只报警）；管网准稳态（忽略管内惯性）；泵曲线二次拟合；射流不计空气阻力；阀 K 随开度按 K/开度² 简化；示例管路参数是假设值
