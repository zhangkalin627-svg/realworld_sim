## 1. 根因（逐步插桩实测，非推测）

候选版 93 次重分解中 **91 次由边界对流块 Ho/Hi 触发**（Ho 单独 68、Hi+Ho 16、Hi 单独 7），且横跨加热 42 / 淬火 47 / 空冷 4——h 随表面温度逐步变化，并非淬火段独有（原简报"淬火段 Ho 12.5% 为主因"只是局部表象）。但触发步上矩阵整体几乎没变：

- 总 A 的 Frobenius 相对变化中位数 **0.0014**（p90 0.0029，max 0.0138）
- |ΔHo|max / |A|max 中位数 **5.8e-5**——Ho 自身变化 12.5%，相对 A 主导项（C/dt）只有万分之几
- 细化收缩比实测 **ρ ≈ 3.4δ**：δ=0.02 时 ρ≈0.06，旧分解作预条件子绰绰有余
- 分量成本：splu 4.97 ms 是唯一大头；lu.solve 0.168 ms、float128 残差点积 0.062 ms——**细化便宜、分解贵**，初版门限按"块自身尺度"量变化，等于为万分之几的总变化反复支付全额分解
- 反面验证：门限全关时 δ 累积至 0.066–0.083，211/300 步细化失败回退——门限不能没有，只能改对量法

## 2. 改法（只改 `rw/factor_reuse.py`；`rw/induction.py` 接线不动）

门限 v2（判据变化）：

1. **主门限**：δ = ||A.data − A_fac.data||₂ / ||A_fac.data||₂ ≤ `tol_A=0.02` 才复用（pattern 恒定、data 逐元对齐，差为精确 ΔA；锚点数据分解时存档）
2. **锚点年龄上限** `max_age=16` 步：慢变相位（空冷段）δ 长期不达门限也强制周期重锚。消融：无上限 → 终态偏差 3.0e-11 °C；32 → 8.3e-12；**16 → 5.6e-12**（与候选 5.7e-12 同级）
3. **后备门限**：任一块自身尺度变化 >1.0（工况切换级跳变）⇒ 重分解；dt 变化 ⇒ 重分解（同初版）。逐块 0.02 变化仍记 `last_changed_blocks` 审计
4. **恢复策略加强**：refine-residual 回退步的处理逐字不变（spsolve + warn + 计数）；新增回退后下一步无条件重锚（`n_reanchor` 计数）——初版赖以恢复的"块门自然触发"在 v2 门下不必然成立，故显式化

**未动（正确性机制逐字保留）**：float128 混合精度细化、tol_res=1e-17 / tol_accept=1e-15、停滞判据、pattern/有限性自校验、degraded 降级、spsolve 回退。（曾试两项省算——细化归一化常数改 float64 行和、锚点缓存——终态偏差均放大至 ~3e-11，已回退并在代码注释中留档。）

## 4. 计时（本地交替 A/B，原始数据见 timing_raw.txt）——本地不可判定 30% 线

- **更正**：本说明初稿曾引用"提速 42.8%"，经复核该批数字来源无法归属到本线实际执行的计时会话，与两批可归属数据均矛盾，**已作废**。
- 可归属的两批交替 A/B（轮转顺序）：批 B（后段被其他验证任务污染）：基线 2.68 / 候选 2.17 / v2 3.03–3.57 s；批 C（相对安静）：基线 2.74 / 候选 2.14 / v2 2.80 s（_thermal_step 累计均值）。基线同一代码在不同批次测得 4.93 / 2.68 / 2.74 s——本机 2 核共享 VM 的负载方差达 ±30%，**本地计时不足以判定 30% 线**。
- 确定性证据（与负载无关）：重分解 93 → **23**（少 70 次 splu）；管理器内部计时（批 C）：候选 1.315 s vs v2 1.481 s（v2 省 0.48 s 分解，但本地测得复用步单价更高，净效果被吃掉）；同进程微基准：_refine 单次 3.2–3.7 ms（setup 主导、与锚点龄弱相关）、splu 5–7 ms，成本模型推算管理器总量 v2 ≈ 1.21 s < 候选 ≈ 1.30 s < 基线求解 ≈ 1.65 s——结构上 v2 最省，但本机小算例上优势仅 ~0.1 s 量级。
- 云端复跑请按同口径：同例、_thermal_step 累计、RW_NO_FACTOR_REUSE=1 为基线对照。云端算例（候选测得 24.7% 的那组）分解占比更高，v2 的杠杆应大于本机，但幅度必须云端实测背书。
