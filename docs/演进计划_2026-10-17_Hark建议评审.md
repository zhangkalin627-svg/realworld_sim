## 取舍与排期
- **S1（先做）**：统一示波器/数据检查器——各页"送到示波器"、多次运行叠加、双光标、CSV/PNG 导出（复用 ⑥ 示波器代码）；同时修 README 口径 + 内置"100 kW / 10–20 kHz 淬火电源"默认预设。理由：对标 LTspice/PLECS 后处理，成本最低、立刻解决"看不到、比不了"。
- **S2**：⑧/⑧b 分块实时运行（暂停/单步/继续、运行中调参下一块生效）+ 通用扫参器（右键扫描→曲线族+汇总表）+ 居里点 R(T)/L(T) 动态负载实时接入锁相环（替代能量等效查表）。
- **S3**：IGBT 开关级模型（datasheet Eon/Eoff/Vce(sat)）+ 导通/开关损耗 + Foster 热网络到结温 + 死区/ZVS 裕度检查（=对标结论②）；厂商 SPICE 模型导入-验证流程（=对标结论①）；故障注入库补 IGBT 短路/开路/丢脉冲/退饱和，每种输出保护动作时间与器件应力。
- **S4**：只读可点击方框图（主回路+控制回路块图，点块开参数/波形；服务"拼设备 JSON 拓扑"方向）+ 工程保存（参数/程序/结果单文件 JSON 包）。
- **S5（缓）**：整机时间轴驱动 three.js 3D 机床（Factory I/O 式）；结构/流体/沙盒页时间滑块。
- **明确不做**：拖放式原理图编辑（与 AI/参数驱动主方向冲突）。
