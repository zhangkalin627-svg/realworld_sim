## 二、改进方案（与设计稿 v1.3 合并为一条线）

载体决策【确定，沿用演进计划 S4a】：视觉标杆的载体是 **web 演示层**（canvas 实时渲染，Hark 演示即 web 单文件）；桌面 app 保留为工程内核/计算后端，不往桌面界面上堆视觉投入。

- **P1 演示层主控台落地（v1.3 稿→可运行 web 页）**：v1.3 三页静态稿转为动态页——波形改 canvas 实时滚动（数据来自真实仿真后端，ws/轮询），读数实时刷新；配色严格走 rw_themes.css token；展示规范徽章/局限清单组件内置。
- **P2 扫描淬火过程动画（对标演示第 3 节，用我们的精确模型驱动）**：侧视动画——线圈移动、工件按热力色带变色（token 色带：常温灰→600℃暗红→770℃鲜红+居里细白线→1000℃橙→1100℃黄白）、喷淋、截面硬层生长；倍速档。每帧数据由 InductionQuenchSim 输出驱动，不手写假读数（展示规范 §6）。
- **P3 演示叙事**：自动演示步序（动作+讲解段+时长）、开场口径声明、折叠模型说明、收尾诚实清单——按展示规范 §5 模板内置到场景。
- **P4 多主题**：深色高档默认，其余主题后补（演进计划 19:58 用户指示已有）。
