## 2. 金相/硬化模型推导（公开出处，可复算）
### 2.1 奥氏体化（加热侧）
- JMAK 方程：f(t) = 1 − exp(−(k·t)^n)，k = k0·exp(−Q/(R·T))。
- 42CrMo 感应淬火参数（已核实出处）：Q = 2.04×10⁶ J/mol，ln k0 = 230.78，n = 0.427；Kissinger 法从不同加热速率膨胀曲线拟合；连续变温用 Scheil 可加性法则离散叠加。
  出处：钟汉烈, 汪舟, 甘进, 等. 基于ABAQUS-Matlab对42CrMo钢表面感应淬火奥氏体化参数的研究[J]. 表面技术, 2020, 49(9)。（馆存 02_CCT-TTT快速加热奥氏体化）
- 45 钢目前无同等级公开动力学参数 → v1 用 Ac1=725°C / Ac3_fast=830°C 的阶跃近似（现仓库口径），v2 上 JMAK+Scheil，45 钢参数标"待查证"，用 42CrMo 参数组做参照演示并明示钢种差异。

### 2.2 连续冷却转变（冷却侧，CCT）
- 42CrMo 实测+模拟 CCT（已核实出处）：Ac1=743°C，Ac3=792°C；冷速 <0.5°C/s → 先共析铁素体+珠光体；0.5–10°C/s → 贝氏体量先增后降、马氏体渐增；>10°C/s → 马氏体基+少量贝氏体；近全马氏体需 >100°C/s；20°C/s 时硬度约 700 HV（DIL805L 膨胀仪实测 + JMat-Pro 模拟互证）。
  出处：李凯等. 42CrMo钢连续冷却转变曲线的测定与分析（馆存同夹）。
- v1 组织判据：按冷却曲线 800→500°C 平均冷速分四档（<0.5 / 0.5–10 / 10–100 / >100 °C/s），对应 珠光体+铁素体 / 贝氏体混合 / 马氏体+贝氏体 / 近全马氏体；锚点硬度用 700HV@20°C/s 与手册 HRC 值校准。

### 2.3 马氏体转变量（淬火后组织分数）
- Ms 估算：Andrews 经验式 Ms(°C) = 539 − 423·C − 30.4·Mn − 17.7·Ni − 12.1·Cr − 7.5·Mo（wt%）。
  出处：K. W. Andrews, Empirical formulae for the calculation of some transformation temperatures, JISI, 1965（公开，Cambridge phase-trans.msm.cam.ac.uk 收录同款计算程序）。
  45 钢（C 0.45, Mn 0.65）→ Ms ≈ 329°C，与现仓库 340°C 同量级（v1 沿用 340，注明 Andrews 估算口径）。
- 马氏体体积分数：Koistinen–Marburger：f_m = 1 − exp(−α·(Ms − T))，α ≈ 0.011 K⁻¹。
  出处：D. P. Koistinen & R. E. Marburger, A general equation prescribing the extent of the austenite-martensite transformation in pure iron-carbon alloys and plain carbon steels, Acta Metallurgica, 1959。
- 最终组织 = 扩散型部分（CCT 分档定比例）× 剩余奥氏体的 KM 马氏体化；v1 简化为"冷速档定组织类别 + KM 定马氏体分数"。

### 2.4 外观颜色（黑体辐射）
- Planck 黑体辐射谱 → CIE 1931 XYZ → sRGB；配色函数用解析近似。
  出处：Wyman, Sloan, Shirley. Simple Analytic Approximations to the CIE XYZ Color Matching Functions, JCGT, 2013（公开期刊）；Planck 定律为公开物理学。
- 工程效果：约 550°C 暗红可见 → 900°C 橙红 → 1100°C 黄；喷淋区表面骤冷迅速回到暗色。发光亮度按 Stefan–Boltzmann 相对缩放，标注"颜色为按表面温度渲染的仿真示意"。

## 3. 场景设计
- 几何：圆柱工件（直径/长度可调）沿轴向匀速穿过固定感应线圈，喷淋环随线圈后置（间距可调）→ 等价于工件坐标系中的移动热源+移动冷却区，准稳态求解。
- 输入：扫描速度 v（如 2/10/20 mm/s 对比）、功率、频率、喷淋介质档位（复用 QUENCHANTS）、延迟间距。
- 输出面板：
  1) 外观动画：工件表面按 T(x,z,t) 渲染黑体色；
  2) 金相面板：硬化层深度（f_m≥50% 的深度，mm）、深度方向组织分数条（马氏体/贝氏体/珠光体+铁素体）、HRC 硬度曲线；
  3) 读数全部标"仿真结果"+简化假设角标。
- 对比叙事：快扫→浅层、冷速高→全马氏体高硬度；慢扫→深层但自回火/冷速不足→贝氏体比例升、硬度降；不喷水→空冷珠光体化，红热缓慢消退。

## 4. v1 简化假设（明示）
1) 轴对称二维准稳态，忽略周向与端部效应；2) μr(T) 线性塌缩近似（现仓库口径，真实 B-H 非线性未建模）；3) 相变潜热并入 cp 峰；4) 喷淋换热系数按介质档位查表，不建模流场；5) 金相只算深度方向一维切片；6) 不算应力/变形/开裂；7) 不算晶粒长大与碳化物溶解细节；8) 组织-硬度锚点为 42CrMo 实测+45 钢手册值的混合校准，标"估算"。

## 5. 分阶段计划（每阶段配 validate_*.py，可复算，rc0≠语义通过）
- P1 扫描热循环：移动热源+移动喷淋区接入 induction.py；输出各深度 T(t)、t8/5、峰值温度场；validate 复算：v 加倍→t8/5 与硬化深度同向变化、能量守恒残差<1%。
- P2 金相/硬化模型：materials.py 新增 austenize_jmak（Scheil 叠加）、cct_classify（四档）、martensite_km、hardness_v2；validate 复算锚点：Andrews Ms(45钢)≈329±15°C、KM 在 Ms−100°C 时 f_m≈0.67、20°C/s→约 700HV（42CrMo 参照）、慢冷→珠光体档。
- P3 外观与面板：黑体色渲染（JCGT 近似）+金相面板接入演示页框架（Hark UI 规范深色主题）；validate 色彩：800K/1200K/2000K 色温→RGB 单调性与 hue 区间断言。
- P4 评审与打磨：Hark/星野邮件评审（物理趋势+演示叙事），按评审意见修订；对照李凯/钟汉烈趋势表逐项核对。
