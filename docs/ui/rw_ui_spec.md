# realworld_sim 配色与界面规范 v1.0（含评审 demo_page_v1）
作者：Hark（hark-kalin@agentmail.to）　状态：设计稿，未在软件里实机验证；对比度数值为估算，落地后请用实际屏幕看一眼。

## 一、设计原则
1. 深色分层、少用大面积亮色：背景只用 4 级明度台阶，亮色只给"数据"和"状态"。
2. 一个颜色只表一件事：热力=橙，电压=黄，电流=绿，频率=蓝，功率=橙（与热同族，因为功率就是发热）。危险=红，仅用于告警。
3. 数据用等宽数字字体，标签用无衬线，数字与单位分字级（单位小一级、降一档灰度）。
4. "仿真结果"标识必须常驻，用警示黄描边小标签，不得省略。
5. 久看不累眼：深色主题最亮文字 #e8edf2（不用纯白），大面积底色不超过 #1b232d；动效饱和度低于静态强调色。

## 二、配色 token（默认深色，数值见 rw_themes.css）
| 类别 | token | 深色值 | 用途 |
|---|---|---|---|
| 背景层级 | --bg-0/1/2/3 | #090c11 / #0e1319 / #141a22 / #1b232d | 页面 / 区块 / 卡片 / 悬浮与控件 |
| 描边 | --line / --line-strong | #242e3a / #33404f | 卡片边 / 控件边 |
| 文字 | --text-1/2/3 | #e8edf2 / #9aa7b4 / #66727e | 主 / 次 / 注释 |
| 强调 | --accent | #5eb1ff | 选中、焦点、链接 |
| 热力 | --heat / --heat-hi | #ff6a1f / #ffb04a | 工件温度、功率、发热 |
| 电气 | --ele-v/i/p/f | #f2cf4a / #4fe38a / #ff6a1f / #5eb1ff | 电压 / 电流 / 功率 / 频率 |
| 状态 | --ok/--warn/--danger | #4fe38a / #f2b84a / #ff5d5d | 锁定正常 / 注意 / 故障 |
| 图表 | --chart-1…5, --chart-grid | 蓝橙绿黄紫，网格 6% 白 | 多曲线按序取色 |

热力色带（工件变色，从冷到热）：#5a6572（常温）→ #8c2f2a（约 600℃ 暗红）→ #c9302a（770℃ 居里点，鲜红）→ #ff6a1f（约 1000℃ 橙）→ #ffd27a（>1100℃ 黄白）。只在居里点处加一条细白线标记，不要整体渐变得太艳。

## 三、界面规范
- 圆角：控件 6px，卡片内部块 10px，卡片 14px。
- 卡片：底 --bg-2，1px --line 描边，阴影 --shadow-card（深色靠内顶部高光+外部弱阴影，浅色用柔和投影，黑白主题无阴影）。
- 字级：11（注释）/12（卡片标题）/14（正文、控件）/18（分区标题）/28（KPI 数值）/40（单个主指标）；字重 400/500/650。
- 间距尺度：4 / 8 / 12 / 16 / 24 / 32，卡片内边距 16，卡片间距 12–16，分区间距 24。
- 按钮：次级=--bg-3 底+--line-strong 边，悬停边变 --accent；主按钮=--accent 底、--bg-0 字。一屏最多一个主按钮。
- 滑块/进度：轨道 --bg-3，已走部分用 --heat（时间轴）或 --accent（普通参数）。
- 图表与波形约定：线宽 2px（主曲线）/1px（辅助）；网格 --chart-grid；游标竖线虚线 --text-3；曲线未到达部分降到 35% 透明度（已走/未走对比）；每图最多 3 条曲线；单位写在标题里。波形：电压=--ele-v 方波，电流=--ele-i 正弦，不要同图再加第三色。
- 动效：能量流虚线速度正比于功率但限幅；仅动"在变的东西"；无限循环的装饰动画一律不要；提供"减少动效"开关。

## 四、主题与场景（同一套 token，只换数值）
- dark 深色高档（默认）：长时间盯屏、演示、车间弱光。
- light 简约浅色：白天办公、截图进文档/汇报、投影仪。
- mono 黑白：打印黑白稿、色弱友好、强调波形形状而非颜色（靠线型区分：实线/虚线/点线）。
切换方式：给根节点设 data-theme；PySide6 里把 token 读成字典，用 QSS 模板字符串替换即可，不要在控件里写死十六进制。

## 五、对 demo_page_v1 的评审（直接说问题）
截图 t=1.5s 与 css 变量已看（动态效果只看了静态图，动效分是按代码与截图推断）。
| 项 | 分 | 理由 |
|---|---|---|
| 配色 | 7.5 | 底色层级和蓝/橙/黄/绿分工清楚，方向对。扣分：绿 #4dff88、黄 #ffe14d 过饱和刺眼，状态文字"锁定·跟踪"荧光绿久看累；工件条整片暗红偏脏，缺热力渐变 |
| 层次 | 7 | 五个 KPI→控制条→双图→双曲线，动线顺。扣分：KPI 五张等权，没有主次；"说明"文字沉在波形卡片底部几乎没人读；底部大片空白 |
| 动效 | 7 | 能量流虚线+波形+游标是加分项；节点橙色外发光在 7 个块里 5 个同时亮，焦点被稀释，属多余 |
| 档次 | 6.5 | 比成果展示页差在：缺图形化主体（能量流是纯文字方块）、曲线卡太素、排版"表单感"重 |

最影响档次的 3 点（按改进收益）：
1. 能量流与工件换成图形化主视觉：节点用线稿图标（电网/整流/IGBT/谐振/变压器/线圈/工件），连线用粗细+流速表示功率，只让"当前瓶颈/正在变化的节点"发光；工件条改成圆柱/截面剖视并按热力色带渐变，居里点画白线。这块占屏幕上半 40%。
2. 建立主次：把"工件温度"和"频率"做成 40px 大数字主指标（放左上，带迷你趋势线），功率/相位/状态降为小号；状态用图标+文字，颜色降一档饱和度。
3. 曲线卡补"叙事"：在 f(t)/P(t) 上标注事件点（过居里点、PLL 锁定、功率拐点）并用一句话注释；已走部分实线、未走部分 35% 透明（现在已有，但对比再拉开）；去掉底部空白，让两张曲线卡占满剩余高度。

内容层面提醒（不是视觉问题）：KPI 显示工作频率 31.93 kHz，而 HFQ6 基线是 10–20 kHz（标称 15 kHz）。若这是演示场景 B 的谐振点漂移结果，请在页面上注明"场景参数，非 HFQ6 基线"，避免被误读。
