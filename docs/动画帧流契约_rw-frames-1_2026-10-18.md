# 动画帧流契约 rw-frames/1（2026-10-18 v1）

目标：感应加热淬火页"打开即有动画、改参数即见加热过程动画"。
三层架构：L0 预计算帧包（打开即播）→ L1 流式 FEM 帧（边算边播）→ L2 1D 即时预览（参数改动 <1.5s 出预览，FEM 帧到达后替换）。
一切输出标"仿真结果/快速预览·估算"，永不称实测（展示规范 v1）。

## 帧包 JSON Schema（rw-frames/1）
```json
{
  "schema": "rw-frames/1",
  "mode": "precalc | stream | preview",
  "params": {"freq_kHz": 20, "power_kW": 5.9, "t_heat": 3.0, "t_quench": 3.0, "t_air": 6.0,
             "medium": "water_spray", "mur_cold": 20.0, "nonlinear": false,
             "geom": {"neck_od": 22, "wall": 3, "neck_len": 50, "zone": 20, "coil_id": 30, "coil_h": 25}},
  "grid": {"nr": 40, "nz": 120, "r_mm": [0.0, "..."], "z_mm": [0.0, "..."]},
  "frames": [{"t": 0.0, "T_C": [[25.0, "..."]]}],
  "monitor": [{"t": 0.0, "T_surf": 25.0, "T_inner": 25.0, "I_coil_A": 0.0}],
  "coil": {"z0_mm": 15.0, "z1_mm": 35.0, "r_in_mm": 15.0},
  "result": {"T_max": 896, "t85_surface_s": 4.21, "HRC_surface": 57, "case_depth_mm": 1.8},
  "meta": {"badge": "仿真结果", "solver": "fem-fast | fem-accurate | preview-1d", "generated_at": "ISO8601"}
}
```
- `T_C`：每帧 nz×nr 的摄氏温度二维数组（先行后列 = z 行 × r 列）。帧间隔建议 0.1~0.25 s（物理时间），加热段可密、空冷段可疏。
- `mode=stream` 时帧经 SSE 逐帧推送（`data: {"t":..,"T_C":[[..]]}\n\n`），流末尾推 `data: {"done":true,"result":{...}}`。
- 几何固定为 BottleNeckGeometry 默认（与 Web 版①页一致）；r=0 为轴心。

## API（Web 版新增）
- `POST /api/induction/stream`  body=①页参数 JSON → 创建流式任务，返回 `{"job_id": "..."}`
- `GET  /api/job/{id}/stream`  SSE：首帧 ≤3s（功率模式）；帧同契约；`done` 结束。
- `POST /api/job/{id}/cancel`  参数再改时前端取消旧任务。
- `GET  /static/precalc/{name}.json`  L0 预计算帧包（默认工况 default.json 必含）。
- 目标温度模式：先按预估功率开播（meta.solver="fem-fast(est-power)"），find_power 完成后推 `{"corrected":true,"power_kW":...}` 并续播校正帧。

## 验收标准（A1~A5）
A1 打开页面 ≤1s 自动播默认工况动画（L0）。
A2 改频率/功率：命中预计算立即播；否则流式首帧 ≤3s；1D 预览 ≤1.5s。
A3 快速档功率模式完整动画 ≤10s（参考硬件实测计算 6.9s）；目标模式 find_power 校正 ≤30s（实测 20.1s）。
A4 动画=温度场云图随时间演化+工件火色+监测点曲线同步生长；全程"仿真结果"徽章。
A5 未运行态无大空白。
